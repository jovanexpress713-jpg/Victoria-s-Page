# دليل التسليم للعميل (Handoff)

وثيقة تشغيل مختصرة تُسلَّم مع المشروع عند التسليم النهائي.

## 1) ماذا يستلم العميل؟

- موقع متكامل (تعريفي + متجر + مختبر + معرفة + مساعد ذكي) بواجهة عربية RTL.
- لوحة إدارة داخلية (`/admin`) لإدارة: العملاء المحتملين، طلبات التسعير والعروض، المتابعات، معرض الأعمال، كتالوج المتجر وطلباته.
- ملفات نشر جاهزة: Docker/nginx، Netlify، Vercel، واستضافة ثابتة.
- اختبارات آلية وفحوص جودة (typecheck/lint/tests/build) تعمل في CI.
- أصول هوية مولّدة: أيقونات بكل المقاسات + صورة مشاركة اجتماعية.

## 2) بيانات الدخول والتشغيل الأول

| البند | القيمة |
| --- | --- |
| مسار الإدارة | `https://<النطاق>/admin` |
| كلمة المرور | ما حدده العميل عند البناء (`VITE_ADMIN_PASSWORD_HASH`) |
| تطوير محلي | `npm install && npm run dev` — كلمة تجريبية `victoria2026` |
| رقم واتساب الرسمي | `+967 771 119 726` (قابل للتغيير من البيئة) |

> عند نسيان كلمة المرور في الإنتاج: ولّد بصمة جديدة وأعد البناء والنشر (لا تُخزن كلمة نصية في المستودع أبداً).

## 3) العمليات الدورية (بدون مبرمج)

1. **نسخة احتياطية**: مركز الإدارة ← زر «نسخة احتياطية» (ملف JSON شامل) — يُنصح أسبوعياً وقبل مسح المتصفح.
2. **استعادة**: زر «استيراد نسخة» من نفس اللوحة.
3. **تقارير**: أزرار CSV (الطلبات/العملاء/المتجر) تفتح مباشرة في Excel بالعربية.
4. **تعديل المعرض/المتجر**: من تبويبي «معرض الأعمال» و«المتجر والطلبات» (إضافة/تعديل/حذف/استعادة افتراضي).
5. **متابعة العملاء**: قائمة المتابعات (إغلاق/إعادة فتح/إضافة/حذف) + إرسال العروض عبر واتساب بضغطة.

## 4) حدود النظام (بشفافية)

- بيانات الـ CRM محفوظة في متصفح جهاز المشرف (LocalStorage): جهاز واحد = نسخة واحدة. عند تعدد المشرفين أو الأجهزة يلزم ربط خادم مركزي (خطة توسّع موثقة في ARCHITECTURE).
- المساعد الذكي محرك قواعد عربي داخل المتصفح (ليس اشتراك LLM مدفوع) — قابل للترقية لاحقاً بدون تغيير الواجهة.
- الصور الافتراضية من Unsplash (روابط خارجية): يُستبدلها العميل بصوره الحقيقية من لوحة الإدارة، ولو تعذر تحميلها يظهر بديل أنيق تلقائياً.

## 5) ضمانات التسليم

- `npm run check` يمر بالكامل (أنواع، lint، اختبارات، بناء).
- CI يمنع دمج أي كسر على الفرع الرئيسي.
- الموقع يحترم: RTL كامل، وصولية (تنقل لوحة مفاتيح، تباين، تقليل حركة)، وSEO (وسوم لكل مسار + sitemap + robots + بيانات منظمة).

## 6) الدعم والتشغيل

- أعطال النشر: راجع `docs/DEPLOYMENT.md` قسم قائمة التحقق.
- تغيير الهوية/الرقم/النصوص المركزية: ملف واحد `src/config/site.ts`.
- إعادة توليد الأيقونات: `npm run assets`.
