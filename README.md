# Victoria Line Soft — الموقع الرسمي

تطبيق ويب حديث مبني بتقنية **React 19 + TypeScript + Vite 6** وتنسيقات **Tailwind CSS v4**، بواجهة عربية أصيلة (RTL) متجاوبة مع الهاتف والكمبيوتر، وسمة داكنة/فاتحة متكاملة. يشمل: موقع تعريفي، متجر حلول جاهزة، مختبر تجارب حي، مساعد استكشاف ذكي، مركز معرفة، ونظام إدارة عملاء وطلبات (CRM) مدمج مع نسخ احتياطي.

---

## ✅ جاهزية الإنتاج بسرعة

| الأمر | الوظيفة |
| --- | --- |
| `npm install` | تثبيت الحزم |
| `npm run dev` | خادم تطوير على المنفذ 3000 (http://localhost:3000) |
| `npm run build` | بناء نسخة الإنتاج في `dist/` + توليد `sitemap.xml` و`robots.txt` |
| `npm run preview` | معاينة نسخة الإنتاج على المنفذ 4173 |
| `npm run check` | فحص شامل: أنواع + lint + اختبارات + بناء |
| `npm test` | تشغيل اختبارات Vitest |
| `npm run assets` | إعادة توليد الأيقونات وصورة المشاركة من المصدر المتجهي |

## 🧭 أقسام ومسارات التطبيق

1. **الرئيسية (`/`)**: واجهة بصرية تفاعلية ثلاثية الأبعاد، موجّه المشروع (Project Architect) بثلاث خطوات، شبكة الخدمات، معرض الاتجاهات الرقمية مع نافذة تفاصيل لكل عمل، منهج العمل، والأسئلة الشائعة.
2. **المتجر (`/store`)**: كتالوج منتجات رقمية جاهزة مع سلة شراء، وإتمام الطلب عبر واتساب برسالة منسّقة تلقائياً.
3. **الحلول والخدمات (`/products`)**: كتالوج الخدمات مع تصفية حسب التصنيف ومنهجية التطوير.
4. **المختبر الحي (`/lab`)**: أربع تجارب تفاعلية داخل المتصفح (متجر، لوحة أعمال، استوديو هوية، تطبيق جوال).
5. **مساعد Victoria AI (`/ai/sales`)**: محادثة إرشادية تصنّف الاحتياج وتقيّم الفرصة وتسجلها في الـ CRM.
6. **مركز المعرفة (`/insights` و `/insights/:slug`)**: مقالات متخصصة مع بحث وفلاتر وفحص أعمال سريع.
7. **تواصل (`/contact`)**: نموذج طلب عرض سعر محفوظ في الـ CRM + مساعد جانبي لجمع المتطلبات.
8. **مركز الإدارة (`/admin`)**: لوحة تحكم محمية: Pipeline العملاء، طلبات التسعير والعروض، **قائمة المتابعات**، سجل المساعد الذكي، إدارة معرض الأعمال وكتالوج المتجر، طلبات الشراء، وأدوات **نسخ احتياطي/استيراد/تصدير CSV**.
9. **واتساب (`/whatsapp`)**: تحويل مباشر للمحادثة الرسمية.

## 🔐 لوحة الإدارة والأمان

- **التطوير المحلي**: كلمة المرور التجريبية `victoria2026` (تظهر كتلميح في صفحة الدخول أثناء التطوير فقط).
- **الإنتاج**: تُضبط كلمة المرور عبر بصمة SHA-256 في متغير البيئة `VITE_ADMIN_PASSWORD_HASH` (انظر `.env.example` و`docs/HANDOFF.md`). بدونها تُقفَل لوحة التحكم مع رسالة توضيح — لا توجد كلمة مرور افتراضية في الإنتاج.
- الجلسة تنتهي تلقائياً (افتراضياً 120 دقيقة)، وهناك قفل مؤقت بعد 5 محاولات فاشلة.
- البيانات تُحفظ محلياً في متصفح المشرف (LocalStorage محمي): نزّل نسخة احتياطية دورياً من مركز الإدارة ← «نسخة احتياطية»، أو صدّر CSV.

> تنبيه مهني: حماية الواجهة مناسبة لإدارة محتوى تسويكي وعملاء محتملين، لكنها لا تغني عن خادم مصادقة وقاعدة بيانات مركزية إذا تعدد المشرفون أو تعددت الأجهزة. انظر `SECURITY.md`.

## 🎨 السمة والهوية

- السمة الافتراضية **داكنة** (هوية العلامة) مع بديل **فاتح** كامل عبر رمز تصميم (CSS Variables) في `src/index.css` — كل الصفحات تستهلك الرموز نفسها لضمان الاتساق.
- تفضيل المستخدم يُحفظ ويُطبَّق قبل أول رسم (`public/theme-init.js`) لمنع وميض الثيم.
- يحترم الموقع تفضيل تقليل الحركة (`prefers-reduced-motion`).

## 🗂️ بنية المشروع

```

│  ├─ context/        مزود السمة
│  ├─ data/           بيانات الكتالوج والمقالات والمعرض
│  ├─ hooks/          usePageMeta لوسوم SEO لكل مسار
│  ├─ pages/          صفحات التطبيق (تحميل كسول)
│  ├─ services/       storage (CRM) · auth (المصادقة) · ai (المساعد)
│  └─ test/           إعداد بيئة الاختبار
└─ docs/              ARCHITECTURE · DEPLOYMENT · HANDOFF
```

## 🚢 النشر

الخيارات المدعومة جاهزة في المستودع:

- **Docker + nginx**: `docker build -t vls . && docker run -p 8080:80 vls` (تفاصيل في `docs/DEPLOYMENT.md`).
- **Netlify**: `netlify.toml` + `public/_redirects` (توجيه SPA وترويسات أمان وتخزين مؤقت).
- **Vercel**: `vercel.json` (rewrites + ترويسات).
- **أي استضافة ثابتة**: ارفع محتويات `dist/` مع توجيه كل المسارات إلى `index.html`.

قبل النشر اضبط `VITE_SITE_URL` (لوسوم المشاركة وخريطة الموقع) و`VITE_ADMIN_PASSWORD_HASH` (للوحة الإدارة)، ثم `npm run build`.
