# Victoria Line Soft

موقع وخدمات رقمية مبني بـ FastAPI وJinja2، بواجهة عربية RTL ومتجاوبة مع الهاتف والكمبيوتر. يتضمن صفحة تعريفية، خدمات، مركز مقالات، محادثة استكشاف احتياج العميل، طلبات عروض أسعار، ولوحة متابعة داخلية.

## التشغيل المحلي

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
uvicorn app.main:app --reload
```

ثم افتح `http://127.0.0.1:8000`.

## المسارات الأساسية

- `/` الصفحة الرئيسية وأداة اكتشاف الحل المناسب
- `/products` الخدمات
- `/contact` محادثة الاستكشاف وطلب عرض سعر
- `/insights` مركز المعرفة والمقالات
- `/admin/login` تسجيل دخول الإدارة
- `/admin` لوحة متابعة العملاء وطلبات التسعير (تتطلب تسجيل الدخول)
- `/health` حالة الخدمة وإعدادات التشغيل غير السرية

## متغيرات البيئة

اضبطها من إعدادات الاستضافة (مثل Vercel)، ولا تحفظها داخل Git أو ملفات عامة.

| المتغير | الغرض | مطلوب للإنتاج؟ |
|---|---|---|
| `VLS_SESSION_SECRET` | مفتاح توقيع جلسات الإدارة، استخدم قيمة عشوائية طويلة | نعم |
| `VLS_ADMIN_PASSWORD_HASH` | تجزئة كلمة مرور الإدارة بصيغة PBKDF2 الموضحة أدناه | نعم للوصول إلى الإدارة |
| `DATABASE_URL` | رابط PostgreSQL دائم (مثل Neon) | نعم قبل حفظ طلبات العملاء فعليًا على استضافة لا تضمن بقاء ملفات SQLite |
| `OPENAI_API_KEY` | تفعيل ردود الذكاء الاصطناعي الفعلية | اختياري؛ دون المفتاح يعمل رد احتياطي ويظهر AI_UNAVAILABLE |
| `OPENAI_MODEL` | اسم النموذج، الافتراضي `gpt-4.1-mini` | اختياري |
| `WHATSAPP_NUMBER` | رقم واتساب بصيغة دولية مع أرقام فقط، الافتراضي `967771119726` | اختياري |
| `VLS_SECURE_COOKIES` | ضبط `true` لتفعيل كوكيز آمنة عبر HTTPS؛ مفعّل تلقائيًا على Vercel ما لم يُضبط خلاف ذلك | موصى به |

### إنشاء مفتاح جلسة آمن

شغّل محليًا، ثم انسخ الناتج إلى إعدادات البيئة السرية:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

### إنشاء تجزئة كلمة مرور الإدارة

لا تضع كلمة المرور العادية في متغير البيئة. شغّل السكربت محليًا، وأدخل كلمة مرور قوية عند الطلب، ثم خزّن الناتج فقط في `VLS_ADMIN_PASSWORD_HASH`:

```python
import getpass
import hashlib
import secrets

password = getpass.getpass("Admin password: ")
salt = secrets.token_bytes(16)
digest = hashlib.pbkdf2_hmac("sha256", password.encode("utf-8"), salt, 310000)
print(f"pbkdf2_sha256${salt.hex()}${digest.hex()}")
```

## قاعدة البيانات والاستمرارية

يدعم التطبيق PostgreSQL عبر `DATABASE_URL`، ويستخدم SQLite للتطوير المحلي. **لا تعتمد على ملف SQLite محلي لحفظ طلبات حقيقية في بيئة استضافة مؤقتة**؛ قد لا تبقى البيانات بعد إعادة التشغيل أو نشر نسخة جديدة. اربط PostgreSQL دائمًا، واختبر إنشاء طلب واسترجاعه بعد إعادة النشر قبل الإعلان عن جاهزية استقبال العملاء.

يعرض `/health` ما إذا كان التطبيق يستخدم PostgreSQL وما إذا كان رابط قاعدة بيانات دائمة مهيأً، لكنه لا يثبت وحده نجاح النسخ الاحتياطي أو جاهزية الاستعادة.

## الاختبارات

```bash
python -m compileall app
python -m pytest -q
```

تعمل الاختبارات نفسها تلقائيًا عبر GitHub Actions عند الدفع إلى `main` أو إنشاء طلب دمج.

## Docker

```bash
docker build -t victoria-line-soft .
docker run --rm -p 8000:8000 --env-file .env victoria-line-soft
```

لا ترفع ملف `.env` إلى Git.

## قبل الإطلاق العام

- اضبط `VLS_SESSION_SECRET` و`VLS_ADMIN_PASSWORD_HASH` من إعدادات الأسرار.
- اربط PostgreSQL دائمًا واختبر بقاء طلب تجريبي بعد إعادة النشر.
- أضف `OPENAI_API_KEY` إذا أردت ردود AI فعلية؛ وجود الواجهة وحده لا يعني أن مزود AI متصل.
- اختبر تسجيل دخول الإدارة والخروج وحماية المسارات.
- راجع الخصوصية والاحتفاظ ببيانات العملاء والنسخ الاحتياطي وصلاحيات الوصول.
- تحقق من حالة النشر الفعلية من لوحة الاستضافة بعد كل دمج؛ نجاح GitHub Actions لا يثبت نجاح نشر Vercel.
