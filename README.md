# Victoria Line Soft

تطبيق ويب حديث مبني بتقنية **React 19 + TypeScript + Vite** مع تنسيقات **Tailwind CSS**. يوفر واجهة عربية أصيلة (RTL) متجاوبة مع الهاتف والكمبيوتر، مع تجارب تفاعلية ثلاثية الأبعاد، مختبر حي، مساعد ذكي لاستكشاف المشاريع، مركز معرفة ومقالات، ونظام إدارة عملاء وطلبات (CRM) مدمج.

---

## 🚀 التشغيل والتطوير المحلي

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير (المنفذ 3000)
npm run dev

# بناء نسخة الإنتاج
npm run build

# فحص الأخطاء والأنواع
npm run lint
```

بعد تشغيل الخادم، افتح المتصفح على `http://localhost:3000`.

## 🧭 أقسام ومسارات التطبيق

1. **الرئيسية (`/`)**:
   - واجهة بصرية ثلاثية الأبعاد تفاعلية مع مجسم متجاوب بحركة المؤشر.
   - **موجّه المشروع (Project Architect)**: معالج تفاعلي من 3 خطوات يساعد العميل على اختيار نوع الحل، وتحديد الهدف التجاري، والجدول الزمني، مع توليد ملخص فوري وزر مباشر لإرسال الطلب.
   - شبكة الخدمات وحلول الأعمال.
   - **معرض الاتجاهات الرقمية (Showcase)**: مفاهيم تصميمية ورسوم بيانية تفاعلية لـ (المنصات، التجارة الرقمية، أنظمة الأعمال، الهوية البصرية، تطبيقات الجوال).
   - منهج العمل المكون من 4 مراحل.
   - الأسئلة الشائعة القابلة للتوسيع (FAQ Accordion).

2. **الحلول والخدمات (`/products`)**:
   - كتالوج الخدمات الرقمية مع تصفية التصنيفات (مواقع ومتاجر، أنظمة وتطبيقات، هوية وتصميم، ذكاء اصطناعي).
   - بطاقات الخدمات مع تفاصيل نطاق العمل وأزرار البدء.
   - بانر الانتقال للمختبر الحي.
   - منهجية التطوير الواضحة.

3. **المختبر الحي (`/lab`)**:
   - مجسم منتج تفاعلي ثلاثي الأبعاد يدور مع حركة المؤشر.
   - **4 تجارب حية داخل المتصفح**:
     1. **متجر تفاعلي**: إضافة منتجات للسلة، حساب الإجمالي وتعديل الكميات فوريًا.
     2. **لوحة أعمال**: تبديل النطاق الزمني (7 أيام / 30 يوماً) مع مؤشرات أداء ورسم بياني متحرك.
     3. **استوديو الهوية**: تخصيص اسم العلامة والعبارة التعريفية واختيار الألوان مع معاينة مباشرة.
     4. **تطبيق جوال**: هاتف تجريبي مع تبديل شاشات (الرئيسية / المهام / حسابي).

4. **مساعد Victoria AI (`/ai/sales`)**:
   - محادثة رقمية ذكية لاستكشاف أفكار المشاريع وتأهيل العملاء.
   - أزرار استفسار سريعة ورسائل توجيهية.
   - تقييم فوري وتحديد للخطوة التالية مع روابط إرسال الطلبات.

5. **مركز المعرفة والرؤى (`/insights` & `/insights/:slug`)**:
   - مقالات عملية متخصصة في الذكاء الاصطناعي والتجارة الإلكترونية والأمن الرقمي.
   - شريط بحث وفلاتر تصنيفات.
   - فحص أعمال سريع (**A Quick Business Check**) يقدم توصية فورية لاحتياج شركتك.
   - صفحات قراءة كاملة للمقالات مع خلاصات عملية ومصادر موثوقة.

6. **تواصل معنا وابدأ مشروعك (`/contact`)**:
   - نموذج طلب عرض سعر رسمي مع حفظ فوري في نظام الـ CRM الداخلي.
   - مساعد AI جانبي لجمع المتطلبات ومناقشة تفاصيل الفكرة.

7. **مركز الإدارة (`/admin` & `/admin/login`)**:
   - تسجيل دخول محمي (كلمة المرور التجريبية: `victoria2026`).
   - إحصائيات حية: العملاء، طلبات التسعير، الفرص الساخنة، والمتابعات.
   - Pipeline العملاء مع تصنيف المراحل ومعدلات التأهيل.
   - إدارة طلبات التسعير وكتابة مسودات العروض.
   - زر إرسال مباشر يفتح تطبيق **واتساب** برسالة مخصصة للعميل.
   - سجل مراجعة محادثات Victoria AI.

8. **تواصل واتساب المباشر (`/whatsapp`)**:
   - توجيه مباشر إلى محادثة واتساب الرسمية: `+967 771 119 726`.

- **الخطوط**: Alexandria & Cairo (عربي أصيل)
- **التخزين**: LocalStorage CRM Persistence Engine
